# TechXpert — αρχική έκδοση ιστοσελίδας

## Περιεχόμενα
- `index.html`: αρχική σελίδα στα ελληνικά
- `styles.css`: responsive σχεδίαση μαύρο/κυανό
- `app.js`: μενού κινητού, φόρμα και αναζήτηση επισκευής (προς το παρόν χωρίς backend)
- `assets/techxpert-banner.png`: το banner που έστειλες

## Δοκιμή στον υπολογιστή
Άνοιξε το `index.html` σε browser. Για καλύτερη δοκιμή χρησιμοποίησε έναν τοπικό web server ή ανέβασε το φάκελο σε προσωρινό hosting.
