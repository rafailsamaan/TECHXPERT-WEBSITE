# TechXpert — δωρεάν Cloudflare backend τιμών

Το project κρατά το υπάρχον site και προσθέτει Cloudflare Worker + D1 database και κρυφή σελίδα διαχείρισης τιμών στο `/admin.html`. Η δημόσια ιστοσελίδα εμφανίζει αυτόματα τις ενεργές τιμές που καταχωρίζεις. Το email αιτημάτων μέσω Google Apps Script παραμένει όπως ήταν.

## Μία φορά: ρύθμιση backend

Απαιτείται λογαριασμός Cloudflare. Τα Workers και D1 έχουν δωρεάν επίπεδα χρήσης με όρια· δεν χρειάζεται να αγοράσεις domain. Η Cloudflare μπορεί να ζητήσει ενεργοποίηση/επιβεβαίωση χρέωσης για ορισμένες δυνατότητες, οπότε έλεγξε τα όρια του λογαριασμού σου.

1. Κάνε αντίγραφο ασφαλείας του τωρινού GitHub repository. Αντικατάστησε τα αρχεία με αυτά του ZIP (το `public/` είναι ο ιστότοπος).
2. Στο Cloudflare Workers & Pages δημιούργησε D1 database με όνομα `techxpert-prices` ή άνοιξε terminal με Wrangler.
3. Από το terminal, μέσα στον φάκελο του project, τρέξε:

   ```bash
   npx wrangler d1 create techxpert-prices
   ```

4. Η εντολή θα εμφανίσει ένα `database_id`. Άνοιξε `wrangler.toml` και αντικατάστησε το `PASTE_D1_DATABASE_ID_HERE` με αυτό το ID.
5. Δημιούργησε τον πίνακα:

   ```bash
   npx wrangler d1 execute techxpert-prices --remote --file=./schema.sql
   ```

6. Όρισε μυστικό κωδικό διαχειριστή (μην τον βάλεις σε αρχείο ή GitHub):

   ```bash
   npx wrangler secret put ADMIN_PASSWORD
   ```

   Πληκτρολόγησε έναν ισχυρό, μοναδικό κωδικό όταν ζητηθεί.

7. Κάνε deploy:

   ```bash
   npx wrangler deploy
   ```

   Αν το repository συνδέεται με αυτόματο deploy στο Cloudflare, έλεγξε ότι εκτελείται από τον σωστό φάκελο και ότι τα παραπάνω βήματα D1/secret έχουν ολοκληρωθεί πρώτα.

## Χρήση

- Δημόσιος τιμοκατάλογος: άνοιξε την αρχική ιστοσελίδα, επίλεξε κατηγορία, μάρκα, μοντέλο και επισκευή. Αν υπάρχει ενεργή αντιστοιχία, εμφανίζεται η τιμή. Διαφορετικά εμφανίζεται «κατόπιν εκτίμησης».
- Διαχείριση: άνοιξε `https://ΤΟ-DOMAIN-ΣΟΥ/admin.html`, βάλε τον κωδικό `ADMIN_PASSWORD`, και πρόσθεσε/επεξεργάσου/απενεργοποίησε/διέγραψε τιμές. Η αλλαγή είναι διαθέσιμη στον δημόσιο τιμοκατάλογο στην επόμενη αναζήτηση.
- Το κλειδί διαχειριστή φυλάσσεται μόνο ως Cloudflare secret. Το admin page το κρατά προσωρινά στο `sessionStorage` του browser μέχρι να κλείσει η συνεδρία ή να γίνει αποσύνδεση.

## Δοκιμή μετά το deploy

1. Άνοιξε `/api/prices` — πριν καταχωρίσεις τιμές πρέπει να επιστρέφει `{"ok":true,"prices":[]}`.
2. Άνοιξε `/admin.html`, συνδέσου και καταχώρισε μια δοκιμαστική τιμή.
3. Άνοιξε ξανά `/api/prices` και βεβαιώσου ότι η ενεργή τιμή εμφανίζεται.
4. Στην αρχική σελίδα επίλεξε την ίδια συσκευή/επισκευή και βεβαιώσου ότι η τιμή εμφανίζεται.

## Σημείωση για τις τιμές

Καταχωρίζεις μόνο τιμές που έχεις εγκρίνει. Το σύστημα δεν επινοεί τιμές. Ό,τι είναι ενεργό φαίνεται δημόσια. Το πεδίο σημείωσης μπορεί να εμφανιστεί μαζί με την τιμή.
